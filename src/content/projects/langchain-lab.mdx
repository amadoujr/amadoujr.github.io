## Le projet

**langchain-lab** est un monorepo d’apprentissage orienté portfolio : mini-projets qui enchaînent les briques utiles en prod — agent + tools, RAG, graphe de recherche web, assistant documentaire « conforme », puis **hotline vocale** support.

L’objectif n’est pas un notebook isolé, mais des apps relançables (CLI, API SSE, UI React) avec des contraintes réalistes : ancrage, tools, refus, rate limits, audit, HITL.

**Démo live (étape 05)** : [voice-hotline.onrender.com](https://voice-hotline.onrender.com/)

## Le parcours

| Étape | Focus |
|---|---|
| **01 — Agent basics** | Agent Gemini + tool HTTP + mémoire `InMemorySaver` |
| **02 — RAG classique** | Chunking, embeddings, retrieval tool (Gutenberg) |
| **03 — Research chat** | LangGraph web research, retry/refuse, rate limits, UI |
| **04 — DocuSafe** | RAG souverain (politiques FR) : citations, refuse, audit |
| **05 — Hotline vocale** | Agent tools FAQ + Web Speech + edge-tts + tickets HITL |

## Hotline vocale (étape 5) — live

Assistant support : micro ou texte → agent qui appelle `search_faq` / `propose_ticket` → réponse + TTS. Déployé sur Render (free), sans PyTorch pour tenir en 512 Mo.

## DocuSafe (étape 4)

Pitch « entreprise » : répondre **uniquement** à partir d’un corpus interne. Hors périmètre → refus, pas d’invention.

## Research chat (étape 3)

Contrepoint de DocuSafe : corpus **ouvert** (web), graphe LangGraph, quotas IP, Docker prêt.
