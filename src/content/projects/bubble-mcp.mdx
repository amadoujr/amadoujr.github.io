## Pourquoi ce serveur

L'outil métier interne de l'entreprise tourne sur Bubble.io. Pour que les assistants IA puissent lire / écrire dans cette base, il fallait un connecteur **standardisé** — d'où l'implémentation d'un serveur **MCP (Model Context Protocol)**.

MCP est un protocole ouvert (initialement Anthropic, vendor-agnostic) qui standardise la communication entre LLMs et systèmes externes.

## Capacités

- **Auto-discovery** : découvre automatiquement les data types de l'app Bubble
- **CRUD complet** sur tous les data types
- **Workflow execution** : déclenche les API workflows définis dans Bubble
- **Respect des privacy rules** de Bubble
- **Mode read-only / read-write** configurable pour la sécurité
- **Type-safe** : expose les types pour chaque opération

## Compatibilité

Compatible avec tout client MCP — Claude Desktop, Claude Code, IDEs, et n'importe quel agent qui implémente la spec MCP.

## Mon rôle

Architecture du serveur, mapping des data types Bubble vers les tool schemas MCP, gestion des privacy rules, packaging et documentation.
