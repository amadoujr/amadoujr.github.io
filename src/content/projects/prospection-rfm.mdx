## Contexte

Refonte du process de prospection B2B chez Meet My Mama. Objectif : passer d'une prospection à l'intuition à une prospection **data-driven**.

## Briques construites

### 1. Segmentation RFM
Calcul des scores **Recency / Frequency / Monetary** sur la base client historique, puis clustering pour identifier les profils (champions, à risque, dormants, etc.).

### 2. Scoring prospects "Everlost"
Identification et scoring des prospects "everlost" — ceux qui ont eu un contact mais n'ont pas converti. Réactivation prioritaire des plus prometteurs.

### 3. Enrichissement multi-sources
Pipeline d'enrichissement via Company Enrich API :
- Domain extraction depuis le website
- Récupération industry / size / location / tech stack
- Gestion du rate limiting, retries, logging
- Tracking des companies skipped/failed

### 4. Préparation Attio
Mapping et import des données prospect dans Attio (nouveau CRM). Spec de mapping documentée pour reproductibilité.
